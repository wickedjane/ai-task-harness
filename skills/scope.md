# scope — 범위와 설계 결정

목표: 경과 15~30분에 핵심 흐름·성공 기준·제외 범위를 정한다.

1. 공식 README·기존 코드·확인한 요구사항을 바탕으로 사용자 흐름 하나와 필요한 화면·데이터를 정리한다.
2. AI와 대안을 비교하고 최종 선택 이유·포기한 범위를 기록한다. 이미 제공된 스택·구조를 우선 활용한다.
3. 구현 예산 90분을 기준으로 위험 지점 두세 개와 검증 방법을 정한다.
4. 서버·저장소·권한은 실제 요구와 실행 환경에 맞춰 선택한다. 필요한 입력 검증·보안·오류 처리를 과설계라는 이유로 빼지 않는다.
5. 지금 쓰지 않는 추상화·기능·의존성은 줄인다. 파일 수나 특정 프레임워크를 일률적으로 제한하지 않는다.

산출물은 핵심 흐름·성공 기준·제외 범위와 주요 결정이다. 공식 문서 양식이 있으면 거기에 통합한다.
