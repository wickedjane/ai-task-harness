# 하위 작업 계약

- 작업 ID / 담당 역할:
- 질문 또는 만들 산출물:
- 연결된 요구사항 / 완료 기준:
- 실제 작업 루트:
- 읽을 입력 파일·관련 스킬·확인된 사실:
- 수정 허용 파일 (읽기 전용이면 없음):
- 변경하지 않을 파일 / 다른 작업자 소유:
- 테스트 실행 허용 여부 / 임시 출력 경로 / 공유 자원:
- 인터페이스 / 선행 조건:
- 허용 모델·도구·외부 접근 범위:
- 예상 종료 시각 / 통합에 남길 시간:
- 막히면 보고할 내용:
- 추가 위임: 기본 불가

반환: 결론 / 근거 / 변경 파일 / 실행한 검증과 결과 / 미실행·한계.
시간 예산과 역할 지시는 런타임의 강제 제한을 대신하지 않는다.
