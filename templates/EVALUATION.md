# 결과 평가와 근거

공식 양식이 있으면 통합하고 해당 목적의 항목만 채운다. 대안 비교가 필요 없으면 비교표 대신 아래 판정/설명 근거표를 사용한다.

앱·결과 파일·보고서에 같은 판정/근거표가 있으면 입력·설정 버전과 해당 위치만 연결한다. 아래 표를 중복 작성하지 않고 결과에 없는 평가 근거·한계만 보충한다.

- 주된 목적 (계획 생성 / 품질·위험 판단 / 자료 분석·설명) / 사용자 목표·산출물:
- 반드시 지킬 조건 / 유효성 검사 방법:
- 적용한 판정 기준·출처·버전 / 자동 처리와 사람의 결정 범위 (해당할 때):
- 기준안 / 비교할 개선안:
- 평가 데이터 버전·범위·표본 수 / 학습 데이터와 분리 여부:
- 실행 환경·시드/반복 조건 / 실제 실행인지 합성 예시인지:

| 지표 | 의미·단위·분모 | 좋은 방향 | 선택 이유 | 계산·검증 방법 |
|---|---|---|---|---|
| | | 최소 / 최대 / 목표 범위 | | |

| 실행·버전 | 방법·설정 | 유효 여부·위반 | 지표 결과 | 계산 시간 | 실행 근거 |
|---|---|---|---|---|---|
| | | | | | |

## 판정 또는 설명의 근거 (해당할 때)

| 판단 대상 또는 주장 | 적용 기준·버전 또는 출처·시점 | 관측값·계산·인용 위치 | 판정 또는 결론 | 미확인·추가 확인·다음 조치 |
|---|---|---|---|---|
| | | | 적합 / 부적합 / 미확인 또는 근거로 확인되는 결론 | |

판단형은 필수 항목별 판정과 근거를 남기고, 분석형은 주요 주장별 출처/계산을 연결한다. 기준·단위·범위가 다른 항목을 하나의 점수로 섞지 않는다. 근거가 없다는 사실을 적합이나 0점으로 바꾸지 않는다. 이후 사람이 내린 결정은 자동 판정과 구분한다.

- 선택한 차트와 축 / 이 차트가 답하는 질문:
- 기준안보다 좋아진 것 / 나빠진 것 / 차이가 없는 것:
- 없는 데이터·정답·사례 때문에 확인 못한 주장:
- 선택과 이유 / 조건이 바뀌면 다른 안을 고를 기준:

가중치가 다른 목적값·다른 평가셋을 같은 척도처럼 비교하지 않는다. 정답 없이 ROC-AUC를 만들지 않는다. 불가능 증명과 시간 내 해 미발견을 구분한다. 작은 평가셋의 결과를 전체 품질로 일반화하지 않는다.
