# 작업 상태 (메인 작성)

필요한 경우에만 사용한다. 기존 PLAN·DECISIONS와 같은 내용을 중복 유지하지 않는다.

- 목표 / 마감 / 지금 확인한 남은 시간:
- 확정된 사실과 중요한 결정:
- 변경 파일과 현재 검증 상태:
- 미해결 필수 항목 / 다음 행동:
- 현재 세션·모델 등 관찰 가능한 설정 (모르면 미확인):

| 작업 | 실제 실행 ID | 담당 | 수정 소유권 | 의존 작업 | 상태 | 근거·반환 위치 | 중단·종료 확인 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

상태 예: 대기 / 실행 / 결과 회수 / 통합 검증 / 실패 / 중단 확인 / 종료.
재개 시 먼저 현재 파일과 실제 작업 상태를 확인한다. 이 기록은 모델 내부 상태의 완전한 복원본이 아니다.
