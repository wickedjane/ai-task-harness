# 입력 데이터 점검

원본을 수정하지 않고 현재 환경에 있는 도구로 확인한다. 대규모 입력은 먼저 파일 크기·샘플 범위를 확인한다.

1. 인코딩·구분자·헤더·행 수·필드 타입을 확인한다. 숫자처럼 보이는 식별자의 앞자리 0을 임의로 없애지 않는다.
2. 필수 필드 결측과 키 중복을 세고, 중복 판단 기준과 제거 여부를 명시한다. 결측을 자동으로 0으로 바꾸지 않는다.
3. 날짜·시간대·단위·금액·분모를 확인한다. 의미가 불명확한 값은 추정으로 표시한다.
4. 집계 전후 행 수를 비교하고 작은 표본을 손으로 대조한다. 표본 결과를 전체 결과로 부르지 않는다.
5. 모델 평가 데이터라면 학습·평가 누수와 중복을 확인한다. 특정 과제에 필요하지 않으면 이 단계를 생략한다.

결과에는 파일·행 수·주요 필드·문제 항목·집계식·실행 근거를 남긴다. 제공되지 않은 데이터나 평가 수치를 만들어 채우지 않는다.
