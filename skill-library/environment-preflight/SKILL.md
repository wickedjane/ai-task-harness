# 환경 확인

처음 5분 안에 작업을 시작할 수 있는 최소 경로를 찾는다. 기존 프로젝트와 과제 안내를 먼저 읽는다.

1. 현재 디렉터리·제공 파일·기존 지침을 확인한다. 환경변수 전체, 인증 파일, 키 내용은 출력하지 않는다.
2. 필요한 실행기만 버전 확인한다. 예: 웹이면 Node·패키지 파일, 데이터면 Python·설치 라이브러리. 없는 도구를 전부 설치하려 하지 않는다.
3. 제공 AI의 모델·권한·승인 대기를 확인하고 짧은 읽기 요청이 완료되는지 본다. 개인 로그인이나 별도 API 키를 요구하지 않는다.
4. 작업 디렉터리에 식별 가능한 임시 파일 하나를 만들고 읽어 저장 경로를 확인한 뒤 자신이 만든 임시 파일만 제거한다.
5. 웹 과제라면 실제 서버 포트·0.0.0.0 바인딩·제공 Browser 경로를 확인한다. 서버 터미널을 유지한다.
6. 도구는 발견됨 / 실행됨 / 실제 호출 검증됨으로 구분한다. 차단되면 제공 대체 도구로 진행하고 필요한 장애 정보를 남긴다.

완료 결과는 실행 도구·확인 명령·미리보기 경로·미확인 제약을 짧게 적는다. MCP 추가 검토는 필요할 때만 저장소의 guides/MCP_CATALOG.md를 읽는다.
